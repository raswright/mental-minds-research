# Mental Minds Research App

Mental Minds is a small interactive application I built while researching React Native and Expo for my CSCE 490 Research Milestone. The app is designed for people with ADHD, executive-functioning difficulties, or anyone having an overwhelming or low-energy day.

The user enters a task, selects their current energy level, and receives smaller steps based on the type of task and the amount of energy they have available.

## Technologies

- React Native
- Expo
- JavaScript
- npm
- React Native Web

## Features

- Task entry with empty-input validation
- Energy selection from 1 to 5
- Step suggestions for studying, cleaning, presentations, and general tasks
- Smaller preparation steps for users with lower energy
- Clickable completion checkmarks
- Progress bar and completion percentage
- Option to add a custom step
- Start Over confirmation before progress is cleared
- Mobile-style interface that can be previewed in a web browser

## Running the Project

1. Clone the repository.

```bash
git clone https://github.com/raswright/mental-minds-research.git
```

2. Enter the project folder.

```bash
cd mental-minds-research
```

3. Install the required packages.

```bash
npm install
```

4. Start the Expo web preview.

```bash
npm run web
```
